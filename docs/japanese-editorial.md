# サイト全体の日本語推敲（2026-10-15）

## 対象

日本語全28ページ：トップ、会社概要、全20製品、ニュース3件、会社資料ダウンロード、プライバシーポリシー、サイトポリシー。共通ヘッダー・フッター、検索説明文、画像の代替テキスト、仕様表、フォームのラベル、入力検証・処理結果メッセージも確認しました。

## 推敲方針

物流・マテリアルハンドリング分野の用語を用い、顧客向けの説明文を「です・ます」調に統一。見出し・仕様項目・沿革は、読みやすい名詞句・簡潔な表現を使用しました。専門用語は必要に応じて説明を併記しています。

| 項目 | 統一表現・使い分け |
| --- | --- |
| 搬送機器 | コンベヤ、ローラ、モータ、スキャナ、リーダ |
| 荷物の分離 | 単品分離（シングレーション） |
| オーダー単位の集約 | オーダー別仕分け・集約 |
| DWS | 寸法計測・計量・識別 |
| 滞留制御 | ゼロプレッシャーアキュムレーション（無圧滞留） |
| 設備速度 | ソーターのキャリッジは走行速度、コンベヤ等は搬送速度 |
| 設備条件 | 必要処理能力、荷姿、投入条件、運用要件、接続仕様、据付・試運転 |
| 処理能力の単位 | 個/時（数値は維持） |
| 問い合わせ | メールの下書き作成・確認・送信を区別 |
| 個人情報 | 個人情報の取扱い |

## 維持した事項

- 型式、画像、動画、製品の分類と仕様数値。
- 会社名、代表者、所在地、電話番号、設立日、資本金。
- 能力・使用温度・据付工程・電源・保険等の適用条件と個別確認の留保。
- 資料間の処理能力表記差異、参考設置面積、資料基準日の注記。
- フォームとダウンロードの動作。問い合わせの下書き作成だけでは送信されない旨を明確化。
- 既存のPDFファイル。今回はウェブサイト上の日本語が対象。
