# 日本語ページの文字組み調整（2026-10-15）

日本の企業サイトで読みやすいゴシック体の文字組みを目指し、日本語全28ページに共通スタイルを適用しました。

- ローカルフォントを使用。ヒラギノ角ゴシック、游ゴシック、メイリオの順に環境に応じて表示し、外部のウェブフォントは読み込みません。
- 本文は16px・行間1.9倍を基本とし、長文部分は行間2倍。カード本文・仕様表は15px、注記は14pxを基本としました。
- 見出しは太さ700を基本とし、字間、見出し階層、段落間隔を統一。
- 日本語の禁則処理（line-break: strict）を指定。長い型式・メールアドレス等は必要に応じて折り返します。
- 長文の行長を制限し、仕様表の余白・縦位置、売上表の数値右寄せ、数値の桁幅を調整。
- 入力欄の文字は16px、スマートフォンでの文字サイズ・表の余白も調整。

本文・数値・HTML構造は変更していません。英語・中国語には日本語専用の文字組み設定を適用していません。共通CSSの更新に伴い、84ページのCSSバージョンを更新しました。

## 確認

- ビルド、84ページの既存静的チェック、差分の空白チェックに成功。
- 84ページについて、CSSバージョン以外のHTMLに変更がないことを照合。
- 日本語全28ページを1440pxおよび390px幅でブラウザー確認し、ページ幅のはみ出しがないことを確認。
- トップ・会社紹介・資料登録・DWS・SL製品を320px幅でも確認。
- 実際の表示フォントは端末にインストールされたフォントに依存します。Windows実機での表示は未確認です。
